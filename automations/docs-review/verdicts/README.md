# Review verdicts

One file per page, written by `/docs-review` (the `concept-page-review` workflow + doclint).
Each `<page>.md` records the latest verdict — `ship` | `revise` | `major-rework` — the
per-lens findings, and the work list. **A page is handed to Mark only when its verdict here
is `ship`.** Git-tracked, so "done" is external evidence, not a claim in chat.
